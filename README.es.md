# llama-cpp

Este repositorio es el árbol del proyecto llama.cpp (inferencia de LLM en C y C++). No está marcado como fork. El manual es el `README.md` en inglés que ya está en el repositorio: compilación con CMake o el `Makefile`, y los ejemplos de la carpeta `examples`.

Este archivo no sustituye ese manual.
